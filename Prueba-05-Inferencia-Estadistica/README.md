# Prueba 5: Inferencia estadística
**Herramienta:** Python / NumPy

## 📜 Enunciado
"Una empresa de tecnología educativa quiere evaluar el nivel de satisfacción de sus estudiantes con un nuevo curso en línea. Para ello, encuestó a 200 estudiantes y obtuvo datos relacionados con edad, género, puntaje de satisfacción (escala 1–10) y horas de estudio semanales. Como analista de datos, deberás aplicar técnicas de estadística inferencial para calcular intervalos de confianza, realizar pruebas de hipótesis y visualizar la distribución de los datos."

## 🎯 Objetivo
Aplicar estadística inferencial.

## 📊 Resultado
Calculé intervalos de confianza y pruebas de hipótesis sobre datos de satisfacción.
