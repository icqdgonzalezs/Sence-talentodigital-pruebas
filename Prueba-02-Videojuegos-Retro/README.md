# Prueba 2: Sistema de Videojuegos Retro
**Herramienta:** Python

## 📜 Enunciado
"El Arcade local 'Pixeles Retro' está organizando su primer torneo de videojuegos clásicos. Los participantes se registran individualmente indicando su experiencia (nivel del 1 al 5). Se forman equipos de 2 jugadores para competir en juegos cooperativos clásicos. Cada equipo acumula puntos según su desempeño en diferentes juegos arcade. Se necesita un programa que facilite el registro de jugadores, ayude a formar equipos balanceados, mantenga el puntaje de las partidas y genere estadísticas."

## 🎯 Objetivo
Gestionar torneo de videojuegos con equipos.

## 📊 Resultado
Implementé validaciones de datos, formé equipos y calculé el análisis estadístico del rendimiento.
